【プロジェクトの背景】
`manager/record.py`に`ImageTruth`というデータクラスが既に定義されています。

```python
@dataclass
class ImageTruth:
    image_sha256: str          # SHA-256: キー
    operator_value: Optional[float]  # 現場で入力した真値
    operator_note: Optional[str]     # 現場の備考
    scale_min: Optional[float]       # 評価に使うフルスケール下限
    scale_max: Optional[float]       # 評価に使うフルスケール上限
    entered_at: str                  # ISO 8601: 入力時刻
```

これはKP-08（`readings`と画像別真値表から`evaluate.py`が読める`groundtruth.json`形式を生成するコマンド）の前提になるデータです。しかし2026-09-17夜の調査で、**このデータクラスがどこにも永続化されていない**ことが分かりました。DBにテーブルが無く、保存する処理も呼び出す場所もありません。

サイドカーJSON（`manager/sidecar.py`の`SidecarMetadata`）には`operator_value`と`operator_note`はありますが、`scale_min`と`scale_max`（メーターのフルスケール範囲）は含まれていません。
