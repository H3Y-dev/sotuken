SyntaxError: invalid character in identifier

## 1. 原因（バイト単位で確認済み）

13行目以降の**インデントが、通常の半角スペースではなく別の文字になっています。**

バイトを直接確認したところ、`class TestMeterManager(unittest.TestCase):` の次の行から、インデント部分が **`U+00A0`（ノーブレークスペース、UTF-8で `C2 A0`）の繰り返し** になっていました（半角スペースなら `20` のはずが `C2 A0` が4個ずつ並んでいる）。

**見た目はスペースと区別がつきません。** エディタの折り返しや、AIチャットのUI・Wordなどからコードをコピー＆ペーストした際に、自動的に変換されて紛れ込んだものと推測されます。Pythonのインデントは半角スペースかタブしか受け付けないため、構文エラーになります。

## 2. 直し方

`manager/test_manager.py` を開き、**ファイル全体を選択して、インデント部分を通常の半角スペースに置き換えてください。** 具体的には次のいずれかの方法で確認・修正できます。

**確認（何文字混ざっているか数える）:**

```
venv\Scripts\python.exe -c "print(open('manager/test_manager.py', encoding='utf-8').read().count(chr(0xa0)))"
```

0より大きい数が出たら、それが混入しているノーブレークスペースの数です。

**修正の一例（Pythonで一括置換してから、中身を目で確認する）:**

```python
with open("manager/test_manager.py", encoding="utf-8") as f:
    content = f.read()
content = content.replace(" ", " ")
with open("manager/test_manager.py", "w", encoding="utf-8") as f:
    f.write(content)
```

**注意: この置換は機械的にやってよいですが、置換した後に必ずファイルを開いてインデントの深さが崩れていないか目で確認してください。** タブと半角スペースが混在すると、また別のエラー（`TabError`）になることがあります。

修正できたら:

```
venv\Scripts\python.exe -m unittest discover -s manager -p "test_*.py"
```

が通ることを確認してください。
