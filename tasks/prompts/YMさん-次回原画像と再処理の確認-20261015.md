PowerShellで次を実行し、出力を確認（reader_funcにはパスを受け取れる `execute_pipeline` を使用）:
`venv\Scripts\python.exe -c "import os, shutil; from manager.manager import MeterManager; from manager.pipeline_caller import execute_pipeline; from manager.batch import calculate_file_hash; os.makedirs('images_ym', exist_ok=True); shutil.copy('eval/images/meter2.jpg', 'temp_ym.jpg'); exp_sha = calculate_file_hash('temp_ym.jpg'); m = MeterManager('test_ym.db'); res = m.process_image('temp_ym.jpg', 'YM確認計', execute_pipeline, images_dir='images_ym'); os.remove('temp_ym.jpg'); rec = m.get_history()[0]; print('画像存在:', os.path.isfile(rec.image_path)); print('DBパス:', rec.image_path); print('DB_SHA:', rec.image_sha256); print('期待SHA一致:', rec.image_sha256 == exp_sha); print('判定:', rec.status); print('値:', rec.value)"`

手順B: 保存原画像からの再処理と前後比較
続けて次を実行し、出力を確認（get_all_readingsはid降順のためidで突合し、元版不変と新版追加を確認）:
`venv\Scripts\python.exe -c "from manager.storage import Storage; from manager.reprocess import reprocess_image; s = Storage('test_ym.db'); before = s.get_all_readings(); old = before[0]; new_id = reprocess_image(s, old.image_path, 'v_next'); after = s.get_all_readings(); old_after = next(r for r in after if r.id == old.id); new = next(r for r in after if r.id == new_id); print('再処理前件数:', len(before), '再処理後件数:', len(after)); print('元版不変:', old.__dict__ == old_after.__dict__); print('新版 id:', new.id, '新版:', new.pipeline_version); print('SHA一致:', old.image_sha256 == new.image_sha256)"`

受け入れ条件:
- [ ] 1. 一時ファイル削除後も、`images_ym` に原画像が存在していること（`画像存在: True`）。
- [ ] 2. DBの `image_sha256` が元の画像ハッシュと一致していること（`期待SHA一致: True`）。
- [ ] 3. 再処理後、元版レコードが変更されずそのまま保持されていること（`元版不変: True`）。
- [ ] 4. 再処理によって新版（`pipeline_version = v_next`）の2件目レコードが追加され、件数が1→2になること。
