工場のアナログメーター（圧力計・温度計など）を現場のAndroidアプリで撮影し、画像だけをPCへ渡して読み取り、一覧に記録するシステムを作っている。

### 段階2：ビルドとユニットテスト

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
cd C:\卒研\git_stk\sotuken\android
.\gradlew.bat test
.\gradlew.bat assembleDebug
```

- JDKは Android Studio に同梱の JBR を使う。`JAVA_HOME` の行を省くと古いJDKが使われて失敗する。
- SDKは `Android 16.0 (API 36)` が必要（35ではない）。足りなければ Android Studio の `Tools > SDK Manager` から入れる。
- 両方とも `BUILD SUCCESSFUL` になること。失敗したら出力の最後の30行を報告する。
- 詳しい手順は `C:\卒研\git_stk\sotuken\android\README.md` にある。

### 段階3：実機（SO-52E）で動かす（SK-03・SK-05の実機確認）

`android\README.md` の「実機で起動する」の手順で、Android Studio から実機へ入れて起動する。次を1つずつ確かめ、結果を「確認した / 失敗 / 未確認」で書く。

1. 未許可のとき、カメラの許可を求める説明と許可ボタンが出る
2. 許可すると背面カメラのプレビューが出る
3. 撮影すると、画面にファイル名と「キューに追加しました」が出る
4. 撮影するたびに「キュー: N件」が1件ずつ増える
5. 機内モードにしても撮影でき、キュー件数が増える
6. 権限を拒否してもアプリが落ちず、画面に説明が出る

ここで不具合があれば**直さずに報告して止まる**。撮影は段階4に進んでからにする。

### 段階4：デモ動画の素材を撮る

**撮る対象:** 実物の丸い圧力計があればそれを使う。無ければ、リポジトリの `eval\images\meter2.jpg` を印刷するか、別のモニターに大きく表示して撮る。**企業から提供された計器の写真は撮らない・使わない。**

**撮り方:** Android標準の画面録画を使う（クイック設定パネルの「スクリーンレコード」。無ければクイック設定の編集から追加する）。音声は録らない。

**1テイクの流れ（10〜20秒）:**
1. ホーム画面からアプリ「メーター撮影」を起動する（キュー件数が見える状態から始める）
2. メーターにカメラを向け、盤面が画面の中央に大きく入るように1〜2秒止める
3. 撮影ボタンを押す
4. 「キューに追加しました」とキュー件数が1増えたのが見える状態で2秒待つ
5. 画面録画を止める

**2〜3テイク撮る。** 手ぶれや指で画面が隠れたテイクがあっても構わない。良いものを大久保が選ぶ。

**提出するもの:**
- 画面録画の動画ファイル（2〜3本）
- 撮影した写真そのもの（アプリの保存先は `Android/data/jp.sotuken.metercapture/files/Pictures/captures/`）。PCとUSBでつなぎ、エクスプローラーでコピーするか、`adb pull` で取り出す

動画と写真は**Slackに投稿せず**、大久保とのUSBメモリや共有フォルダなど、チーム内の受け渡し方法で渡す。
