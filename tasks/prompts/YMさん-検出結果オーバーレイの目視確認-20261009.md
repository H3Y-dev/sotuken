## 1. 今日やること（1スプリント・約3時間）

### 手順

1. 作業フォルダを開く: `C:\卒研\git_stk\sotuken`
2. 最新のmainを取り込む:
   - `git fetch origin`
   - `git rebase origin/main`
   - 「コンフリクト」という文字が出たら、**自分で直さず**、画面の文字を全部コピーして送る。
3. Web UI（一覧画面）を起動する。起動の方法は `SETUP.md` の「Web UI」の節に書いてあるとおりに行う。
4. 一覧画面の「記録」タブを開き、行を1つ選んでチェックを入れる。
5. 検出結果のオーバーレイ画像（読み取りに使った位置を重ねた画像）が表示されるのを確認する。
6. **3つの行** について、次の表を埋める。

   | 行 | 画像名 | 目盛りの位置は合っている？ | 針の位置は合っている？ | 読み取り値は画像の目盛りと合っている？ | 状態（画面の表示） |
   |---|---|---|---|---|---|
   | 1 | | ○ / × | ○ / × | ○ / × | |
   | 2 | | ○ / × | ○ / × | ○ / × | |
   | 3 | | ○ / × | ○ / × | ○ / × | |

   「分からない」と書いてもよい。その場合は理由を一言書く。
7. 表を大久保に送る。**×が付いた行は、画像を見て何が違うかを一言で書く**（例: 「針の先ではなく軸を指している」）。

### 受け入れ条件（あなたの担当範囲）

- [ ] オーバーレイ画像が、選んだ行ごとに正しく表示される
- [ ] 状態（正常・低信頼・失敗）の表示が、画面に出ている値と一致する
- [ ] 見た目で合わない行があれば、画像名と理由を報告できている

## 2. 守ること

- **プログラムのファイルを変更しない。** 直したくなっても、報告だけにする。
- 企業提供の画像を外部に出さない。画像を見せる相手は大久保だけにする。
- 画面が表示されない、エラーが出た場合は、**エラーの文字全部**をコピーして送る。推測で直そうとしない。
- コミットやpushはしない。

## 3. 作業が終わったら日報を書く（必須）

次の8項目で `日報_YMさん_20261009.md` を作り、Slackへファイルとして投稿する。書式は変えない。

1. 名前と日付
2. 今日のタスク名（タスクIDを付ける: YM-06 の確認）
3. やったこと（3〜5行。着手できなかったことはそう書く）
4. 成果物（「未コミット（確認作業のみ）」と書く）
5. テスト結果（今日は実行しないので「該当なし」と書く）
6. 受け入れ条件の達成状況（上の3項目それぞれ「達成」「未達成」）
7. 詰まったところ・分からなかったこと（最重要。分からなかったことは正直に書く。「特になし」で済ませない）
8. 次に必要なこと（次回やること、大久保に判断してほしいこと）

注意: できなかったことを隠さない。分からないものは「分からない」と書く。絵文字は使わない。
