## 1. 作る物: フォルダ一括取り込みバッチ

対象ファイル: `manager/batch_import.py`（新規）

### 1-1. 関数のシグネチャ

```python
def import_folder(
    folder_path: str,
    manager: "MeterManager",
    reader_func,
    device_name: str = "Default_Device",
) -> Dict[str, List[str]]:
    """folder_path内の未取り込み画像（jpg/jpeg/png）を一括で読み取り、保存する。
    戻り値: {"imported": [処理した画像パス...], "skipped": [二重取り込みでスキップした画像パス...]}
    """
```

- `folder_path` 内の `.jpg` / `.jpeg` / `.png` を列挙する（サブフォルダは見なくてよい）
- 各画像について、後述の「1-2. 二重取り込み判定」でスキップ対象かを先に確認する
- スキップでなければ `manager.process_image(image_path=..., device_name=device_name, reader_func=reader_func)` を呼ぶ（`process_image` の戻り値の扱いは `manager/manager.py` を見て、既存の `main.py` の呼び方に合わせること）

### 1-2. 二重取り込み判定（ハッシュベース）

**画像のファイル名ではなく、中身のハッシュで判定してください。** 同じ写真でもファイル名が変わることがあるため（例: スマホから2回エクスポートすると別名になる）。

`manager/storage.py` に手を入れる必要があります。

1. `meter_readings` テーブルに `image_hash TEXT` 列を追加する（`_init_db_with_conn` のCREATE TABLE文に追加。**既存のDBファイルには自動で列が増えないので、`ALTER TABLE meter_readings ADD COLUMN image_hash TEXT` を、テーブルが既に存在する場合の後方互換として `_init_db_with_conn` 内で `try/except sqlite3.OperationalError` で試みる**、のような形にすること。ゼロから作るテスト用DBと、既に存在する `manager.db` の両方で壊れないようにする）
2. `Storage` に `find_by_hash(image_hash: str) -> Optional[MeterReading]` を追加する（`image_hash` で1件検索、無ければ `None`）
3. `save_reading` に `image_hash: Optional[str] = None` 引数を追加し、INSERT文に含める

ハッシュの計算はSHA-256でよいです。

```python
import hashlib

def compute_image_hash(image_path: str) -> str:
    with open(image_path, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()
```

`import_folder` の中で、各画像について `compute_image_hash` → `storage.find_by_hash` で既存レコードがあれば `skipped` に、無ければ処理して `imported` に入れる、という流れになります（`MeterManager` 経由で `storage` にアクセスする方法は `manager/manager.py` の `self.storage` を参照）。

### 1-3. `main.py` からバッチを呼べるようにする

`main.py` に `--import-folder <path>` 引数を追加し、指定されたら `import_folder()` を呼んで、`imported` / `skipped` の件数を表示する（既存の `--image` / `--history` / `--export-csv` と同じ書き方でよい）。
