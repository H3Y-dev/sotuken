### 1-1. `meter_pipeline.py` の `_detect_center()` への結線

現状の実装（32〜57行目）はこうなっています。

```python
def _detect_center(img):
    h, w = img.shape[:2]
    hough = tick_detect.auto_detect_center(img)
    seed = (hough[0], hough[1]) if hough is not None else (w // 2, h // 2)
    try:
        refined, _ticks = tick_detect.refine_center_iterative(img, seed)
    except Exception:
        refined = None
    if hough is not None and refined is not None:
        shift = math.hypot(refined[0] - hough[0], refined[1] - hough[1])
        if shift > min(h, w) * 0.03:
            return refined, 'corrected'
        return (hough[0], hough[1]), 'hough'
    if hough is not None:
        return (hough[0], hough[1]), 'hough'
    if refined is not None:
        return refined, 'ticks'
    return None, None
```

`resolve_center_consensus(hough, estimate, fit_result, img_shape, ticks=None, ...)` を呼ぶには、**3つの候補それぞれを、今は呼ばれていない別の関数から取ってくる必要があります。**

| 引数 | 求め方 | 注意 |
|---|---|---|
| `hough` | `detect_meter_center_v2.detect_meter_center_from_raw(img)` | **今の `tick_detect.auto_detect_center(img)` とは別の関数です。** `center_consensus.py` のdocstringが期待しているのは `{'center': (x,y), 'radius': r}` のdict形式で、`auto_detect_center` が返す `(x,y,r)` タプルとは形が違います |
| `estimate` | `center_estimate.estimate_center(img, ticks=None)` | mainに実装済み。`_detect_center` からはまだ一度も呼ばれていません |
| `fit_result` | `circle_fit.fit_circle_to_ticks(ticks, method="taubin")` | `ticks` が要る。`tick_detect.refine_center_iterative` が返す2つ目の値（今は `_ticks` として捨てている）を使う |
