## 1. 次の1ステップ: テストを書く

**今回進めるのはこれだけです。** `tests/` フォルダに、`export_to_csv()` のためのテストを1つ追加します。

### なぜテストが要るか（KPくんに伝える言い方）

「動くコードを書けた」の次は、「動き続けることを保証する」段階です。今は自分でファイルを開いて中身を目で見て確認していますが、チームの人数が増えると、誰かが別の場所を直したときにこの関数が壊れても気づけません。**テストは、それを自動で気づけるようにする仕組みです。**

### 進め方（1ステップずつ）

1. **仮のデータを1件だけ用意する。** `readings` に渡す「記録」がどんな形（`r.id`, `r.timestamp`, `r.device_name`, `r.value`, `r.stage`, `r.image_path` を持つオブジェクト）かを、`export_to_csv` の中身を読んで確認する
2. **一時ファイルにCSVを書き出してみる。** `tempfile` を使うと、テスト用のファイルを作って自動で消してくれる
3. **書き出したCSVを読み直して、中身が正しいか確認する。** ヘッダー行と、渡したデータの値が一致しているかを見る
4. **空リストを渡した場合も試す。** ヘッダー行だけのCSVができれば正しい

雛形はこのような形になります（KPくんと一緒に、実際の `readings` の形に合わせて調整してください）。

```python
import csv
import tempfile
import os
import unittest
from manager.export import export_to_csv


class DummyReading:
    def __init__(self, id, timestamp, device_name, value, stage, image_path):
        self.id = id
        self.timestamp = timestamp
        self.device_name = device_name
        self.value = value
        self.stage = stage
        self.image_path = image_path


class TestExportToCsv(unittest.TestCase):
    def test_writes_header_and_rows(self):
        readings = [DummyReading(1, "2026-08-27", "meter1", 42.0, "ok", "img1.jpg")]
        with tempfile.TemporaryDirectory() as d:
            path = os.path.join(d, "out.csv")
            export_to_csv(readings, path)
            with open(path, encoding="utf-8-sig") as f:
                rows = list(csv.reader(f))
        self.assertEqual(rows[0], ["ID", "日時", "機器名", "値", "ステージ", "画像パス"])
        self.assertEqual(rows[1][0], "1")

    def test_empty_list_writes_header_only(self):
        with tempfile.TemporaryDirectory() as d:
            path = os.path.join(d, "out.csv")
            export_to_csv([], path)
            with open(path, encoding="utf-8-sig") as f:
                rows = list(csv.reader(f))
        self.assertEqual(len(rows), 1)


if __name__ == "__main__":
    unittest.main()
```

**このコードをそのまま渡さず、1行ずつKPくんに読ませて、何をしているか説明しながら一緒に書いてください。** `DummyReading` のようなダミークラスを使う理由（本物のデータベースを用意しなくてもテストできる）も、その場で説明するとよいです。
