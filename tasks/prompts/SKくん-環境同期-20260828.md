## 1. 環境を同期する手順（最初に必ずこれをやる）

作業を始める前に、**未コミットの変更が無いことを確認してから**実行してください。

```
git status
git fetch origin
git checkout SKdeveropment
git reset --hard origin/SKdeveropment
```

**注意: `git reset --hard` は手元の未コミット・未push の変更を消します。** 何かローカルに残っている変更があれば、先に `git stash` するか、本人（大久保）に相談してから実行してください。

同期できたか確認:

```

```
