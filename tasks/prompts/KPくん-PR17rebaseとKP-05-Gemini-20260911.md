【rebaseの手順】
1. `git fetch origin` を実行し、出力をそのまま貼り付けてもらってください。
2. `git status` を実行し、作業中のブランチ名と未保存の変更がないことを確認します。出力を貼ってもらってください。
3. `git rebase origin/main` を実行し、出力を貼ってもらってください。
4. コンフリクトが出たら、自分で決めて直させません。`git status` と、競合している `manager/manager.py` の `<<<<<<<`、`=======`、`>>>>>>>` を含む部分を、次のコマンドで貼ってもらってください。`Get-Content C:\卒研\git_stk\sotuken\manager\manager.py`
5. 貼られた箇所だけを上の決定済み方針で直すよう案内し、`<<<<<<<`、`=======`、`>>>>>>>` の3つの印をすべて消したことを確認します。
6. `git add manager/manager.py` を実行します。`git add -A` は使いません。
7. `git rebase --continue` を実行します。次の競合が出たら、同じように出力とスクリーンショットを送ってもらってください。
8. rebase完了後に共通テストコマンドを実行します。mainが121件で、KP-04で追加したテストがそれに加わるため、件数は121件以上になります。全件がOKであることと、実際の件数の両方を記録してください。
