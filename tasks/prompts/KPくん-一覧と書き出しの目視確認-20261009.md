## 1. 今日やること（1スプリント・約3時間）

### 手順

1. 作業フォルダを開く: `C:\卒研\git_stk\sotuken`
2. 最新のmainを取り込む:
   - `git fetch origin`
   - `git rebase origin/main`
   - 「コンフリクト」が出たら、**自分で直さず**、画面の文字を全部コピーして送る。
3. Web UI（一覧画面）を起動する。起動方法は `SETUP.md` の「Web UI」の節どおり。
4. **版の列（確認 1）**: 一覧に「版」の列があり、値が表示されていることを確認する。空欄の行と値の入った行の両方があるか見る。
5. **絞り込み（確認 2）**:
   - 「機器名」の絞り込みで、ある機器を選ぶ。表示される件数をメモする。
   - 別の機器を選ぶ。件数が変わることを確認する。
   - 「日付」の絞り込みでも、件数が変わることを確認する。
   - 件数の数字（変更前・変更後）をそのまま書く。
6. **JSONL書き出し（確認 3）**:
   - 「JSONL書き出し」ボタンを押し、ファイルができた場所を確認する。
   - そのファイルを開く（メモ帳で可）。
   - 行数と、一覧の件数が一致するかを見る。一致しなければ、両方の数字を書く。
   - 1行を選び、中身が `{` で始まるJSONの形になっているか見る。

### 受け入れ条件（あなたの担当範囲）

- [ ] 一覧に「版」の列が表示され、値が見える
- [ ] 機器名と日付の絞り込みで、表示件数と対象の行が変わる
- [ ] 書き出したJSONLの行数が、対象レコード数と一致する
- [ ] 書き出したJSONLの各行が、JSONとして読める形になっている
