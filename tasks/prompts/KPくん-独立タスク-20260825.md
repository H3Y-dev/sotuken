## 1. 何のためにやるのか

工場に、壁一面にアナログのメーターが並んでいます。電流計や温度計の、針がぐるっと動くやつです。
工場の人は毎日、そのメーターを1つずつ見て回って、針が指している数字を**紙やExcelに手で書き写しています**。

このプロジェクトは、それを自動化するものです。他のメンバーが「写真から数字を読み取る」部分を作り、SRくんが「読み取った数字をデータベースに貯める」部分を作りました。

**KPくんが今回作るのは、貯まった数字を「Excelで開けるファイル」として書き出す部分です。** ここが無いと、せっかく貯めた記録を工場の人が見る手段がありません。

## 2. KPくんが作るもの（1つだけ）

**「記録のリストを渡すと、Excelで開けるCSVファイルを作ってくれる関数」を1つ作ります。** これだけです。

### 用語の言い換え

| 出てくる言葉 | KPくんへの言い方 |
|---|---|
| CSV | 「Excelで開けるファイル形式。表計算ソフトが読み込める、シンプルなテキストファイル」 |
| 関数 | 「材料（引数）を渡すと、決まった仕事をして結果を返してくれる、コードの部品」 |
| エンコーディング / utf-8-sig | 「文字をパソコンの中でどう表現するかの決まりごと。日本語をExcelで正しく表示するためのおまじないだと思ってOK」 |
| dataclass | 「1件の記録を表す入れ物。『日時・機器名・値』のように、決まった項目を持つデータのまとまり」 |

```python
# manager/export.py
import csv


def export_to_csv(readings, output_path):
    """
    記録のリストをCSVファイルに書き出す。

    readings: MeterReadingのリスト（storage.pyで定義されているもの）
    output_path: 書き出すファイルのパス（例: "output.csv"）
    """
    with open(output_path, "w", encoding="utf-8-sig", newline="") as f:
        # "utf-8-sig" にしないと、Excelで開いたときに日本語が文字化けする
        writer = csv.writer(f)
        writer.writerow(["ID", "日時", "機器名", "値", "ステージ", "画像パス"])
        # 見出し行を書く。これが表の一番上の項目名になる

        for r in readings:
            writer.writerow([r.id, r.timestamp, r.device_name, r.value, r.stage, r.image_path])
            # 記録を1件ずつ、表の1行として書く
```
