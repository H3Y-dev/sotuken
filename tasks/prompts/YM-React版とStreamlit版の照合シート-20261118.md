   ```powershell
   New-Item -ItemType Directory -Force "$HOME\Desktop\照合_YM_20261118"
   ```

## 3. 両画面の起動方法と止め方

### 起動コマンド
作業フォルダの直下で次を実行します（`--no-streamlit` は付けません）。

```powershell
.\venv\Scripts\python.exe -m pc_api.launcher
```

起動すると、内部の所有プロセス（ポート 8767）、React版の PC API サーバー（ポート 8766）、Streamlit版（ポート 8501）が同じ `manager.db` を使って同時に立ち上がります。

### ブラウザで開くURL
- **React版**: `http://127.0.0.1:8766`
  - **注意**: 必ず `127.0.0.1` で開いてください。`localhost:8766` で開くとサーバーの仕様（Hostヘッダー検証）により `403 forbidden_origin` エラーになります。
  - トークンの手入力は不要です（`pc_api\server.py` が HTML 内の `<meta name="pc-token">` に自動で埋め込みます）。
- **Streamlit版**: `http://localhost:8501`

### 止め方
起動した PowerShell 画面で `Ctrl + C` を押します。React版と所有プロセスが順に停止します。
