## 1. 今日作るもの：値の推移をグラフで見られるようにする

### なぜ必要か

工場の担当者は、CSVやExcelの表で数字が並んでいるだけだと「今日の値は正常範囲か」は分かっても、「先週から少しずつ上がってきている」といった**変化の傾向**には気づきにくいです。値の推移をグラフにすると、この傾向がひと目で分かるようになります。

### 作る関数は1つだけ

**「1つの機器の記録のリストを渡すと、グラフ表示にそのまま使える形に変換してくれる関数」を1つ作ります。**

対象ファイル: `manager/export.py`（`group_by_device` の下に追加）

```python
def readings_to_series(readings):
    """
    1つの機器分の記録のリスト（group_by_deviceで仕分けた後の1機器分、
    または絞り込んだ後のreadingsをそのまま渡してもよい）を受け取り、
    「タイムスタンプ → 値」の辞書を作って返す。
    Streamlitのst.line_chartにそのまま渡せる、グラフ用のシンプルな形にする。

    読み取りに失敗した記録（value が None のもの）はグラフに描けないので、
    ここで除いておく。
    """
```

**受け入れ条件（テストで確認すること）:**
- [ ] `value` が入っている記録だけが辞書に入る（`value=None` の記録は入らない）
- [ ] 辞書のキーは `timestamp`、値は `value`
- [ ] 空のリストを渡すと空の辞書が返る（エラーにならない）

`tests/test_export.py` に、`test_filter_by_device_name` 等と同じ書き方で `readings_to_series` のテストケースを2〜3個追加してください（正常系1つ、`value=None` が混ざっているケース1つ、空リスト1つ、くらいで十分です）。

## 2. （余裕があれば）app.py にグラフを表示する

**時間内に1が終わらなければ、無理に進めなくて大丈夫です。**

`app.py`（Streamlitの画面）の「📜 履歴確認・CSV出力」タブに、次のようなコードを追加すると、機器ごとのグラフが表示できます。

```python
import manager.export as export_module  # ファイル先頭のimport部分に追加

# 履歴一覧の表として表示している箇所のすぐ下あたりに追加
st.subheader("📈 機器ごとの値の推移")
grouped = export_module.group_by_device(manager.get_history())
for device_name, device_readings in grouped.items():
    series = export_module.readings_to_series(device_readings)
    if series:
        st.write(device_name)
        st.line_chart(series)
```

**このコードは目安です。実際の変数名・関数の呼び方は既存の `app.py` の中身を見て合わせてください。**
