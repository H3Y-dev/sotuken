## 2. 守ってほしいこと

- **企業提供画像（`C:\卒研\images\` 配下）を、リポジトリにコミットしない。生成AIにアップロードしない。**
  詳細は `tasks/企業提供画像の取り扱い.md`。**`git add -A` や `git add .` は特に危険です。**変更したファイルを個別に指定して add してください
- **DBファイル（`manager.db`）や出力CSV（`readings_export.csv`）をコミットしない**
- `print()` に絵文字を使わない（この環境ではcp932でクラッシュします）
- パスを絶対パスで直書きしない。`os.path.dirname(os.path.abspath(__file__))` からの相対で書く
- `git pull` を単体で使わない。`git fetch origin` → `git rebase origin/main` の2行を使う
  （`git pull` だとVimという黒い画面が開いて操作できなくなることがあります。開いてしまったら `Esc` → `:wq` → Enter で抜けられます）
