## 1. 次の作業: 「機器別・日付別に絞り込む」機能

### なぜこれが必要か（KPくんに伝える言い方）

「記録をCSVに書き出す」の次に欲しいのは、「見たい記録だけを選ぶ」機能です。たとえば工場の担当者が「meter1の記録だけ見たい」「8月の記録だけ見たい」と思ったとき、全部のデータから欲しい分だけを取り出す仕組みが要ります。これが `filter_readings()` という関数です。

### 進め方（1ステップずつ）

1. **`manager/export.py` に、`export_to_csv` の上に新しい関数 `filter_readings` を追加する。** 引数は `readings`（記録のリスト、今日作った`DummyReading`と同じ形）、`device_name`（機器名で絞り込みたいとき。指定しなければ絞り込まない）、`start_date`と`end_date`（日付の範囲で絞り込みたいとき。指定しなければ絞り込まない）
2. **機器名で絞り込む条件だけ先に書く。** `device_name`が指定されていれば、`r.device_name == device_name`のものだけ残す
3. **日付で絞り込む条件を足す。** `timestamp`は`"2026-08-27"`のような文字列なので、文字列のまま比較で範囲を絞れます（`start_date <= r.timestamp <= end_date`）
4. **テストを書く。** 今日と同じ`DummyReading`を3件くらい用意して（機器名や日付を変える）、絞り込んだ結果が期待通りの件数・中身になっているか確認する

雛形はこのような形になります（KPくんと一緒に、1行ずつ意味を説明しながら埋めてください）。

```python
def filter_readings(readings, device_name=None, start_date=None, end_date=None):
    """
    記録のリストを機器名・日付の範囲で絞り込む。
    指定しなかった条件は絞り込まない（Noneのままなら全件通す）。
    """
    result = readings
    if device_name is not None:
        result = [r for r in result if r.device_name == device_name]
    if start_date is not None:
        result = [r for r in result if r.timestamp >= start_date]
    if end_date is not None:
        result = [r for r in result if r.timestamp <= end_date]
    return result
```

**このコードをそのまま渡さず、1行ずつKPくんに読ませて、何をしているか説明しながら一緒に書いてください。** 特に「Noneなら絞り込まない」という考え方（条件を指定しなければ素通しする）は、他の場面でもよく使う発想なので、その場で説明するとよいです。

テストの雛形:

```python
def test_filter_by_device_name(self):
    readings = [
        DummyReading(1, "2026-08-20", "meter1", 10.0, "ok", "a.jpg"),
        DummyReading(2, "2026-08-21", "meter2", 20.0, "ok", "b.jpg"),
    ]
    result = filter_readings(readings, device_name="meter1")
    self.assertEqual(len(result), 1)
    self.assertEqual(result[0].id, 1)

def test_filter_by_date_range(self):
    readings = [
        DummyReading(1, "2026-08-10", "meter1", 10.0, "ok", "a.jpg"),
        DummyReading(2, "2026-08-20", "meter1", 20.0, "ok", "b.jpg"),
        DummyReading(3, "2026-08-30", "meter1", 30.0, "ok", "c.jpg"),
    ]
    result = filter_readings(readings, start_date="2026-08-15", end_date="2026-08-25")
    self.assertEqual(len(result), 1)
    self.assertEqual(result[0].id, 2)

def test_no_filter_returns_all(self):
    readings = [
        DummyReading(1, "2026-08-20", "meter1", 10.0, "ok", "a.jpg"),
    ]
    result = filter_readings(readings)
    self.assertEqual(len(result), 1)
```
