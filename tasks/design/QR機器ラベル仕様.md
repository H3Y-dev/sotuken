# QR機器ラベル仕様（2026-10-30 ユーザー方向決定）

メーターに貼るQRを、スマホで読んで機器名を入力する。PC側は機器マスターを持たない（10/21決定と整合。名前はQRの中に持つ）。

## QRの中身（ペイロード）
UTF-8のJSON文字列1つ。余計な空白は入れない。

```json
{"v":1,"name":"ボイラー圧力計A-101"}
```

| キー | 必須 | 内容 |
|---|---|---|
| `v` | 必須 | 形式の版。今は `1` |
| `name` | 必須 | 機器名。前後の空白を除き、1〜64文字。制御文字・改行は不可 |
| `unit` | 任意 | 単位（例: `MPa`）。将来、記録タブの単位表示に使う |
| `min`, `max` | 任意 | 目盛りの範囲（数値）。将来、読み取りの誤読補正に使う（今は読み取りに使わない） |

- 読む側は、**知らないキーを無視する**（将来の拡張で壊れないように）。
- `v` が `1` 以外、`name` が無い・空、JSONでない文字列は「機器QRではない」として扱い、機器名は変えずにユーザーへ知らせる。
- 機器名の表記揺れ（全角半角など）は、QRに焼いた名前をそのまま使うことで避ける。PC側で名前を直さない。

## PC側（今回の作業）
- `manager/qr_label.py`: ペイロードの組み立て（`build_payload`）と検証つきの読み取り（`parse_payload`）、印刷用シートの生成（`make_label_sheet`）。
- `tools/make_qr_labels.py`: 機器名の一覧（1行1台のテキストかCSV）から、ラベルを並べたPDFを作る。1枚のA4に2列×5行（10枚）。各ラベルはQR（約25mm角）と機器名の文字（日本語、QRの下）。
- 新しい依存: `qrcode`（QR生成。Pillow は導入済み）。

## スマホ側（SK-07がmainに入ってから、大久保とClaudeで実施）
- SK-07の入力フォームに「QRで機器名を入れる」を足す。読み取れたら機器名の欄に入れ、手で直せる。
- QR読み取りの部品（ML Kit か ZXing）の追加は、導入前に大久保が判断する。
- `parse_payload` と同じ規則（上の表）をKotlinで実装し、同じテストケースで確かめる。

## テストケース（両側で共通）
| 入力 | 結果 |
|---|---|
| `{"v":1,"name":"ボイラー圧力計A-101"}` | name = `ボイラー圧力計A-101` |
| `{"v":1,"name":"  P-1  ","unit":"MPa","extra":1}` | name = `P-1`、unit = `MPa`、extraは無視 |
| `{"v":2,"name":"P-1"}` | 機器QRではない |
| `{"v":1}` / `{"v":1,"name":""}` | 機器QRではない |
| `P-1`（JSONでない文字列） | 機器QRではない |
| name が65文字以上 | 機器QRではない |
