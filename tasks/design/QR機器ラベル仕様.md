# QR機器ラベル仕様（2026-10-30 ユーザー決定）

メーターに貼るQRを、スマホで読んで機器IDと機器名を入力する。機器IDで記録を束ね、表示名（機器名）は後から直せるようにする（機器ID設計に準拠）。

## QRの中身（ペイロード）
UTF-8のJSON文字列1つ。余計な空白は入れない。

```json
{"v":1,"id":"A-101","name":"ボイラー圧力計"}
```

| キー | 必須 | 内容 |
|---|---|---|
| `v` | 必須 | 形式の版。今は `1` |
| `id` | 必須 | 機器ID。`[A-Za-z0-9._-]` の1〜32文字。空・空白・日本語は不可 |
| `name` | 必須 | 機器名。前後の空白を除き、1〜64文字。制御文字・改行は不可 |
| `unit` | 任意 | 単位（例: `MPa`）。将来、記録タブの単位表示に使う |
| `min`, `max` | 任意 | 目盛りの範囲（数値）。将来、読み取りの誤読補正に使う（今は読み取りに使わない） |

- 読む側は、**知らないキーを無視する**（将来の拡張で壊れないように）。
- `v` が `1` 以外、`id` または `name` が無い・不正、JSONでない文字列は「機器QRではない」として扱い、`None` を返す（画面側では機器情報は変えずにユーザーへ知らせる）。
- **v1でnameだけのQR（旧形式）は機器QRではない扱い**（まだ配布していないため後方互換は不要）。
- 機器名の表記揺れ（全角半角など）は、QRに焼いた名前をそのまま使うことで避ける。PC側で名前を直さない。

## PC側（今回の作業）
- `manager/qr_label.py`: ペイロードの組み立て（`build_payload`）と検証つきの読み取り（`parse_payload`）、単一ラベル画像生成（`create_label_image`）、印刷用シートの生成（`make_label_sheet`）。
- `tools/make_qr_labels.py`: 機器の一覧CSV（1列目=機器ID、2列目=機器名）から、ラベルを並べたPDFを作る。1枚のA4に2列×5行（10枚）。各ラベルはQR（約25mm角）と機器名（日本語、QRの下）、その下に小さく機器ID。
- 依存: `qrcode`（QR生成。Pillow は導入済み）。

## スマホ側（SK-07がmainに入ってから、大久保とClaudeで実施）
- SK-07の入力フォームに「QRで機器名を入れる」を足す。読み取れたら機器ID・機器名の欄に入れ、手で直せる。
- QR読み取りの部品（ML Kit か ZXing）の追加は、導入前に大久保が判断する。
- `parse_payload` と同じ規則（上の表）をKotlinで実装し、同じテストケースで確かめる。

## テストケース（両側で共通）
| 入力 | 結果 |
|---|---|
| `{"v":1,"id":"A-101","name":"ボイラー圧力計"}` | id = `A-101`、name = `ボイラー圧力計` |
| `{"v":1,"id":"P.1_a-b","name":"  P-1  ","unit":"MPa","extra":1}` | id = `P.1_a-b`、name = `P-1`、unit = `MPa`、extraは無視 |
| `{"v":2,"id":"A-101","name":"P-1"}` | 機器QRではない（版違い） |
| `{"v":1,"name":"ボイラー圧力計A-101"}` | 機器QRではない（idが無い旧形式） |
| `{"v":1,"id":"A-101"}` | 機器QRではない（nameが無い） |
| `{"v":1,"id":"","name":"P-1"}` | 機器QRではない（idが空） |
| `{"v":1,"id":"圧力計1","name":"P-1"}` | 機器QRではない（idに日本語） |
| `{"v":1,"id":"AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA","name":"P-1"}` | 機器QRではない（idが33文字以上） |
| `{"v":1,"id":"A 101","name":"P-1"}` | 機器QRではない（idに空白） |
| `{"v":1,"id":"A-101","name":""}` | 機器QRではない（nameが空） |
| `{"v":1,"id":"A-101","name":"AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"}` | 機器QRではない（nameが65文字以上） |
| `P-1`（JSONでない文字列） | 機器QRではない |
