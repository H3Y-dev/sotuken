# タスク一覧

各タスクは「単独で着手でき、単独で合否を判定できる」単位に切ってある。
合否はすべて評価基盤（`evaluate.py`）の数値で判定する。

```bash
venv\Scripts\python.exe evaluate.py eval/groundtruth.json -o eval/report.json
venv\Scripts\python.exe -m unittest discover -s tests
```

**全タスク共通の完了条件**
- [ ] `python -m unittest discover -s tests` が通る（過去ログ24件の回帰テストを含む）
- [ ] 評価基盤で改善前後の数値を記録し、悪化していないことを示す
