# Antigravity CLI 使い方マニュアル（全員共通）

このファイルは、卒研メンバー全員がAntigravity CLI（`agy`コマンド）を同じ設定・
同じ手順で使うための統一マニュアルです。**開発未経験でも分かるように書いてあります。**
分からない箇所があれば、このファイルの内容をまるごと自分が使っているAIに貼り付けて、
「この手順通りに一緒にやってほしい」と頼んでください。

出典: [Antigravity公式ドキュメント](https://antigravity.google/docs/cli/reference)（2026-09-07時点）。
コマンド名・設定名は公式ドキュメントの記載に基づいています。

---

## 0. なぜこれが必要か

Antigravityは無料でClaude Sonnet/Opus・Gemini Flash/Proなど複数モデルを使える
コーディングエージェントです。ただし、**人によってモデルの選び方や承認の設定が
バラバラだと、次の問題が起きます。**

- 無料の週次クォータをOpus等の重いモデルで使い切ってしまい、必要な時に使えなくなる
- 承認モードがバラバラだと、ファイルを書き換える前の確認有無が人によって違う
- 「Antigravityでできたはず」「できなかった」の食い違いが起きたとき、
  設定差なのか本当の不具合なのか切り分けられない

**このマニュアル通りに揃えれば、これらを防げます。**

---

## 1. 起動方法

### 1-1. 初回のインストール確認

すでに導入済みなら、PowerShellで次を実行してバージョンが表示されるか確認してください。

```powershell
agy --version
```

何も表示されない・コマンドが見つからないと言われた場合は、以下でインストールします。

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

### 1-2. 起動する

作業したいリポジトリのフォルダに移動してから、`agy`とだけ打ちます。

```powershell
cd C:\卒研\git_stk\sotuken
agy
```

初回は自動でブラウザが開くので、Googleアカウントでサインインしてください。
2回目以降はサインインなしでそのまま起動します。

---

## 2. モデルを選ぶ（`/model`）

Antigravity起動後、プロンプト欄で次を打ちます。

```
/model
```

選択メニューが出るので、`↑`/`↓`で選び`Enter`で確定します。**モデルの選択は
セッションをまたいで保存される**ので、一度選べば次回起動時もそのままです。

### 選ぶ基準（全員共通の既定ルール）

無料枠は**モデルを問わず週次リフレッシュ**（5時間ごとの回復は無料枠には無い）ため、
軽いモデルを既定にして温存するのが全員にとって得です。

| モデル | いつ使うか |
|---|---|
| **Gemini 3.8 Flash (Low)（既定・全員これから始める）** | 通常の作業はすべてこれでよい。1回あたりの消費が最も軽い |
| Gemini 3.8 Flash (High) / Gemini 3.1 Pro | Flash (Low)で手に負えない大きめの作業（大規模な読み込み等）だけ |
| Claude Sonnet 4.6 (thinking) | Kotlin/Python等、型やコード規約に厳密さが要る場面で、Flashの出力が期待と違うとき |
| Claude Opus 4.6 (thinking) | **本当に難しい問題だけ。** 原因不明のバグ・複雑な設計判断など。Geminiの約4倍クレジットを消費するとの報告があるので乱用しない |

### Gemini 3.8 Flash (Low) を選ぶ手順

1. プロンプト欄で `/model` と打って `Enter`
2. モデル一覧から `Gemini 3.8 Flash (Low)`（低reasoningの表記）を`↑`/`↓`で選び、`Enter`で確定
3. **迷ったら`Low`を選ぶ。** 3.8 Flashは推論の深さ（thinking level）を`Low`/`High`で切り替えられ、
   `Low`のほうが速く・クォータ消費も少ない。`High`は複雑なタスクで結果が期待と違うときだけ試す

**注意**: Claude系モデルには現在「Thinkingなし」の選択肢がありません。Claude系を選んだ
時点で必ずThinkingが付きます。エフォートを下げたい場合はモデルをGemini Flash (Low)へ
切り替えてください（Claude内でのエフォート調整はできません）。

## 3. 自動承認モード（`always-proceed`）の設定

**全員、これを既定にします。** 毎回の確認を省いて作業を止めないためです。

### 3-1. 設定画面を開く

```
/config
```

（`/settings`でも同じ画面が開きます）フルスクリーンの設定エディタが開くので、
`↑`/`↓`で項目を選び、`Enter`で値を変更、`Esc`で保存して閉じます。

### 3-2. 手順

1. `/config`を開く
2. `Tool Permission`（`toolPermission`）の項目を`↑`/`↓`で選ぶ
3. `Enter`で選択肢を開き、**`always-proceed`を選んで`Enter`で確定**
4. `Esc`で保存して閉じる

| 設定値 | 動き |
|---|---|
| `request-review`（既定値） | 書き込み・コマンド実行・Web操作のたびに確認を求める |
| `proceed-in-sandbox` | サンドボックス内なら自動実行、それ以外は確認 |
| `strict` | 読み取り以外すべて確認（最も慎重） |
| **`always-proceed`（全員これにする）** | **確認なしで全部自動実行（自動承認モード）** |

### 3-3. 全員共通の運用ルール

- **`always-proceed`を既定にする。** 確認待ちで作業を止めないため
- ただし、**危険な操作（`git push --force`、ファイルの一括削除など）を頼むときは注意して見る。** 自動承認モードでも、エージェントに何を頼むか自体は自分で選べる
- `/diff`で実際に何が変更されたかを都度確認する習慣をつける（自動承認で確認プロンプトが出ない分、事後確認が重要）

## 4. よく使うコマンド一覧（最低限これだけ覚える）

| コマンド | やること |
|---|---|
| `/model` | 使うモデルを選ぶ |
| `/config`（`/settings`） | 自動承認モードなどの設定を開く |
| `/usage`（`/quota`） | 残りクォータを確認する |
| `/clear`（`/new`） | 会話をリセットして新しく始める |
| `/diff` | 変更内容を確認する |
| `/help` | コマンド一覧を見る |
| `/exit`（`/quit`） | 終了する |

---

## 5. トラブル時

- **クォータ切れ（`quota reached`等のエラー）**: `/usage`で残量を確認。切れていたら
  週次リフレッシュを待つか、モデルをGemini 3.8 Flash (Low)へ変えて様子を見る
- **意図しないファイル変更をされた**: `/diff`で変更点を確認し、必要ならgitで元に戻す
  （`git checkout -- <ファイル>`、ただし未コミットの変更を消すのでよく確認してから）
- **原因不明の詰まり**: このマニュアル通りの設定（モデル・承認モード）になっているか
  `/model`と`/config`で確認してから、大久保に共有する

---

## 6. 全員共通の既定設定（まとめ）

作業開始時、迷ったらこれに合わせてください。

1. モデル: **Gemini 3.8 Flash (Low)**（`/model`で選択）
2. Tool Permission: **`always-proceed`**（`/config`で選択。自動承認モード）
3. 詰まったら難易度に応じてGemini 3.8 Flash (High) → Claude Sonnet 4.6 (thinking) → Claude Opus 4.6 (thinking) の順にエスカレーション
